# 年计划初版方案

状态：清单在 `year_plan_item`，按 `user_id` 和 `plan_year` 读取。2026 这批是测试数据，写在库里。2027 及以后同一张表另起年份，不在代码里再写一份清单。入口在阶段标题旁边。待确认的条不写入测试数据。

确认方式：按下面的清单从上往下。每条只看四格——类型、挂什么、目标写在哪、日常回不回显。对话里已经定过的标「已对齐」，其余标「待确认」。未确认的不进入实现。

## 页面是什么

年计划不是晨昏、双周、季度之外的第四种报告。它是阶段报旁边的一张清单：年初写下有哪些条，年中改标题或改挂接，年底给没有数据来源的条补一句结果。

入口放在阶段标题旁边，和零钱罐子图标放在晨昏日志标题旁边同一类。点开是弹窗，只展示。弹窗里可以切到整页，编辑只在整页。首页四个入口不增加这一项。

写阶段报时，【战况速览】里的「年度目标完成度」继续写这一段的散文，不把整年勾选再抄一遍。

## 一条里什么能改，什么只读

新增一条时，先写标题，当作计划名称。对象还没在对应场景里建出来，也可以先保存这一条。

关联用两个下拉，都可以先空着：

- 场景：站内已有场景，例如运动、零钱罐子、书 / 电影
- 对象：选定场景之后，列出该场景里已经存在的 id。选中即关联。列表里没有的，说明还没建出来，这条先不挂。不从年计划跳去原功能创建

对象后来建出来了，回到这条，补上场景和 id。一条只关联一个 id。

一条全年只存这些可编辑的字段：

- 标题
- 挂接：场景，以及该场景里的一个 id；可以不挂
- 今年目标：只有原功能记现状、不记目标时才有这个数字
- 结果句：只有不挂接、别处也没有可汇总的数时才有。B 站条数走这里，手写
- 阶段勾选：只有职业相关的条才有。层级和每一层是否完成，存成 JSON

进度不在这条上手填，职业相关的阶段勾选除外。挂着哪个对象，就读那个对象的现状。读的是一整类的累计（运动天数、电影部数）时，选定场景即可，不选单个 id。

年中改主意，改的是标题和挂接。例如年初想去日本、后来改去黄山：钱的放弃和重新分配仍在零钱罐子里完成；年计划上可以留下富士山那条（只读看到罐子已放弃），另起一条挂黄山罐子，也可以把同一条的标题和挂接直接换掉。旧罐子的放弃记录留在零钱罐子里。

## 类型

### 自带目标

对象自己有目标，日常页已经在显示进度。年计划只挂过去，不把年计划再画回那个页面。

现在符合的：梦想罐子（余额 / 目标金额，放弃，按真实消费结清）。

罐子还没建出来时，年计划先留标题，场景先选「零钱罐子」或先空着，对象下拉里没有可选项就不挂。不跳去零钱罐子建空罐子。罐子在零钱罐子里建出来之后，再回到这条，选中那个 id。年计划不拥有罐子的金额、放弃和结清。

跑步计划不放在这里。健身页按计划本身罗列，计划没有「今年 / 明年」。计划内部的完成次数和距离，是这套课表自己的目标，不是年计划要的那句话。年计划要的是今年对哪一套计划收尾、哪一套开启。见下一节。

### 挂已有计划的状态

类型是 `run`。进度只读跑步计划自己的状态和整体进度。计划组变为 completed，这条算完成。不另存一套完成标准。对象本身不加年份。

现在符合的：跑步计划。

- 完成计划 3：挂健身页里名为计划 3 的那一组。只读它的状态和整体进度。
- 开启计划 4：计划还没在健身页建出来时，年计划可以先添加这条的名称。健身页建出计划之后，再选这个计划的 id。显示的是这套计划自己的状态，不是另记一个「已开启」。

健身页继续只罗列计划本身，不回显年计划。

### 只有现状

类型本身就是统计方式，不另存口径字段。`sport_days` 读运动天数，`movie_count` 读电影部数，`book_count` 读阅读本数，`ted_round` 读 TED 当前轮，`ltn_coins` 读金币合计。目标数字只在年计划上改。年计划页读现状，显示「现状 / 今年目标」。

原功能页回显这一行分母，没有输入框，也不出现整张年计划。改目标仍回到年计划。做题站点在另一个网站时，不要求那个站认识年计划；回显放在本站已经能看到该数据的地方。

现在符合的：LTN 金币（`ltn_daily_coins` 能按日期加总，日常做题不设 1500 这个目标）。读书本数走书 / 电影页里当年的「阅读」。TED 当前轮走 `config.env` 里的一个数字，见清单。

### 无数据源

站内没有可汇总的现状，也没有可挂的对象。只保留标题，需要时写一句结果。不回显到别的页面。年底看一次的体重、体脂、睡眠属于这种。阶段报里已有的入睡和起床仍留在阶段报，不挂到年计划这条上。B 站更新条数也属于这种：数据不在站内，页面里记了进展也查不到，只手写结果。

### 阶段勾选

职业相关的条没有站内可查的完成记录，也不适合只留一句结果。一条内部按层级列出阶段，每一层一个勾选，点中即表示该阶段已完成。层级和勾选状态存 JSON。不挂场景，不回显到别的页面。换工作、分享会、产品与各季度功能走这种。
